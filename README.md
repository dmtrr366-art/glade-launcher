# Glade Minecraft Launcher (Online Multi-User & Admin Console)

Полнофункциональный онлайн веб-лаунчер для Minecraft с серверной частью на **Node.js**, поддержкой одновременной работы множества пользователей, панелью администратора (бан/разбан, каталог модов) и локальной базой данных.

## Архитектура проекта

```
launcher/
├── admin.html             # Панель администратора (Управление игроками, Баны, Публикация модов)
├── auth.html              # Страница авторизации (Вход, Регистрация, Сброс пароля)
├── index.html             # Главная страница лаунчера (Hero, Режимы, Новости)
├── mods.html              # Вкладка "Моды" (Каталог с сервера, Установленные, Поиск)
├── settings.html          # Вкладка "Настройки" (ОЗУ, Разрешение, JVM, Java)
├── profile.html           # Вкладка "Профиль" (Ник, Скин, Аккаунт - без статистики/баттлпасса)
├── css/
│   ├── style.css          # Общие стили лаунчера + оверлей блокировки
│   ├── auth.css           # Стили экранов авторизации
│   └── admin.css          # Премиум темные стили панели администратора
├── js/
│   ├── app.js             # Логика клиента: Heartbeat, синхронизация модов, проверка банов
│   ├── auth.js            # Клиентский модуль аутентификации (API + fallback)
│   └── admin.js           # Логика панели администратора (Дашборд, Бан/Разбан, Моды)
├── server/
│   ├── server.js          # Главный сервер Express (порт 3000)
│   ├── db.js              # Локальная база данных (data/db.json)
│   ├── mailer.js          # Сервис отправки 6-значных кодов на Email (Nodemailer / Console)
│   └── routes/
│       ├── auth.js        # REST API аутентификации, me, heartbeat, logout
│       ├── admin.js       # REST API админки: статистика, управление игроками, баны, публикация модов
│       └── mods.js        # REST API каталога модов (публичный для всех клиентов)
├── data/
│   └── db.json            # Локальный файл БД (пользователи, роли, баны, моды, сессии)
├── .env.example           # Пример настроек SMTP-сервера и порта
└── package.json           # Зависимости и скрипты Node.js
```

## Быстрый запуск и сборка приложения

### 1. Запуск в браузере (Web + Server):
```bash
npm start
```
Лаунчер доступен по адресу: **[http://localhost:3000](http://localhost:3000)**

### 2. Запуск в виде нативного десктопного приложения (Electron):
```bash
npm run app
```
Открывает лаунчер в отдельном безрамочном окне с поддержкой нативных кнопок сворачивания/закрытия.

### 3. Сборка готового приложения (Build):
```bash
npm run build
```
Автоматически выполняет полную сборку:
- **`dist/bundle/`** — автономный дистрибутив с сервером, статикой, БД и скриптами быстрого запуска (`start.sh`, `start.bat`);
- **`dist/mac-arm64/` (или `win/`)** — готовое скомпилированное нативное десктопное приложение лаунчера (`Glade Launcher.app` / `.exe`).

Дополнительные команды сборки под целевые ОС:
- `npm run build:win` — сборка инсталлятора под Windows (.exe / portable);
- `npm run build:mac` — сборка под macOS (.dmg / .app);
- `npm run build:linux` — сборка под Linux (.AppImage / .deb).

## 👑 Панель администратора (`admin.html`)

Доступна только пользователям с ролью `admin` (ссылка на админку автоматически появляется в боковом меню лаунчера).

### Возможности админ-панели:
1. **Живой дашборд статистики:**
   - 👥 Всего зарегистрированных игроков;
   - 🟢 Игроков онлайн прямо сейчас (расчет по 2-минутному окну активности);
   - 🚫 Количество заблокированных пользователей;
   - 📦 Общее число модов в каталоге.

2. **Управление игроками:**
   - Поиск по логину и email;
   - Фильтрация: *Все / В сети / Заблокированные / Администраторы*;
   - **Блокировка (Бан):** выбор готовых причин (Читы, Оскорбления, Мультиаккаунт, Багоюз) или ввод своей причины;
   - **Мгновенное действие:** при бане пользователя сервер немедленно аннулирует все его сессии, а в запущенном лаунчере сразу всплывает блокирующий экран;
   - **Разблокировка (Разбан):** в один клик восстанавливает доступ к игре;
   - **Смена ролей:** назначение и снятие прав администратора.

3. **Каталог модов:**
   - Просмотр всех модификаций с версиями, размерами и количеством скачиваний;
   - **Публикация нового мода:** заполнение формы (название, версия, размер, категория, обязательность, описание). Мод мгновенно становится доступен всем игрокам лаунчера во вкладке «Моды»;
   - **Удаление мода:** удаление из каталога с подтверждением.

## 🌐 Онлайн архитектура и клиентский бан

1. **Многопользовательский режим:**
   - Клиенты каждые 15 секунд отправляют фоновый `heartbeat` на сервер (`POST /api/auth/heartbeat`), обновляя время последнего визита (`lastSeenAt`).
   - Администратор видит точное количество активных игроков в реальном времени.

2. **Клиентская защита от забаненных:**
   - При попытке входа заблокированного игрока сервер возвращает ошибку `403` с указанием точной причины бана.
   - Если бан выдан администратором во время работы лаунчера, клиент немедленно блокируется оверлеем с причиной, датой и деактивацией кнопки «Играть».

## 🔐 Авторизация и безопасность

- **Обязательная почта (Email)** при регистрации.
- **Двухфакторная аутентификация по Email:** при каждом входе высылается 6-значный одноразовый код.
- **Восстановление пароля:** по Email с кодом подтверждения.
- **Хеширование паролей:** bcrypt (10 раундов соли).
- **Локальная БД:** хранится в `data/db.json` с изолированным API в `server/db.js`, готовым для переноса на PostgreSQL/MySQL/MongoDB.
